# Python conventions — oxipng-pybind

Read by the `writing-python` skill on invocation. Project deltas only; the procedure, the
strict baseline, and the gate-resolution order live in the plugin.

## Gate

- Run the gate through the Makefile: `make lint AI=1`, `make typecheck AI=1`, and
  `make test AI=1` (ruff, basedpyright, and the Rust plus Python suites). `make ci AI=1`
  runs the full gate.
- Scoped Python tests need the compiled extension. Run `make develop AI=1` once, then
  `uv run --no-sync --group dev pytest tests/<area you changed> -q` (or `-k`). Never run
  bare `python -m pytest`.

## Deltas the resolver can't infer

- First-party import package: `oxipng` (set `[tool.ruff.lint.isort] known-first-party` to
  match).
- PNG optimization lives in the upstream Rust `oxipng` crate. Keep optimizer behavior there,
  not in Python; this package is only the PyO3 binding and its pyoxipng compatibility layer.
- Opt-in ruff families for this repo: none beyond the baseline.
